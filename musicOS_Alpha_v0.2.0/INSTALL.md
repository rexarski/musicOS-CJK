# Installing musicOS v0.2.0-alpha

1. Make sure Rockbox is already installed on your iPod.
2. Connect the iPod to your computer and enable disk access if necessary.
3. Open this release package and copy the included `.rockbox` folder to the **root of the iPod**.
4. Merge it with the existing `.rockbox` folder when your operating system asks. Do not replace/delete your entire existing Rockbox installation.
5. Safely eject the iPod.
6. In Rockbox, open **Settings → Theme Settings → Browse Theme Files** and select `musicOS_v2.cfg`.

The package installs the theme configuration, WPS/SBS files, graphics, UI vector font and the Sunghyun Sans Rockbox fonts required by musicOS.

## Notes

- Target: iPod Video 5 / 5.5G, 320×240.
- CJK support is experimental in this alpha.
- If the theme looks incomplete, verify that the complete `.rockbox` folder from this archive was merged onto the iPod.
