# Changelog

## v0.2.0-alpha

- Added experimental Chinese, Japanese and Korean metadata support.
- Switched the public theme fonts to Sunghyun Sans Disambiguated SemiBold.
- Improved the Home Screen and added the new accent-colour menu selection.
- Added rounded corners to Home Screen album artwork.
- Simplified the Home mini-player by removing Previous/Next buttons and giving metadata more room.
- Added album name to the Now Playing screen.
- Made the Lossless indicator dynamic so it appears only for lossless playback.
- Added multiple UI refinements and fixes.
