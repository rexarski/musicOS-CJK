# musicOS v0.2.0-alpha

musicOS is a custom Rockbox theme for the iPod Video 5 / 5.5G (320×240), inspired by a clean modern music-player interface.

## What's new in v0.2.0-alpha

- Experimental CJK metadata support (Chinese, Japanese and Korean)
- Refined Home Screen and new accent-colour menu selection
- Rounded album artwork on the Home Screen
- Simplified Home mini-player with Previous/Next controls removed for more metadata space
- Album name added to the Now Playing screen (WPS)
- Dynamic Lossless indicator: shown only when the playing file uses a lossless codec
- Additional UI polish and fixes

## Installation

See `INSTALL.md`.

## Compatibility

Designed for iPod Video 5 / 5.5G at 320×240. This is an alpha release; other iPod generations may work but are not guaranteed by this package.

## Font

This release uses converted Rockbox bitmap fonts based on **Sunghyun Sans Disambiguated SemiBold**, an open-source rounded typeface licensed under the SIL Open Font License 1.1. The full font license and copyright notices are included in `FONT-LICENSE.txt`.

Sunghyun Sans project: https://github.com/anaclumos/sunghyun-sans
