musicOS — Alpha 1
=================

A modern, Apple Music-inspired Rockbox theme for the iPod Video 5th / 5.5th generation (320×240).

STATUS
------
This is an ALPHA release. Core Home, Now Playing and Quick Screen functionality is working, but bugs may still exist.

COMPATIBILITY
-------------
Primary target: iPod Video 5G / 5.5G (320×240).
6G / 7G compatibility should be considered experimental until fully validated on hardware.

INSTALLATION
------------
1. Make sure Rockbox is already installed on your iPod.
2. Back up anything important before installing an alpha theme.
3. Copy the .rockbox folder from this archive to the root of the iPod and merge it with the existing .rockbox folder.
4. In Rockbox, open Settings > Theme Settings > Browse Theme Files.
5. Select musicOS_v2.cfg.

Do NOT replace/delete your entire existing .rockbox folder just to install this theme.

ALPHA 1 HIGHLIGHTS
------------------
- Custom musicOS Home screen.
- Dynamic mini-player with album art, title, album/artist and playback state.
- Apple Music-inspired Now Playing screen.
- Custom Quick Screen with volume and brightness sliders.
- Shuffle and Repeat controls with sprite-based states.
- Battery percentage and custom battery icon.
- Lossless indicator on supported formats.
- Pink musicOS menu selection and custom menu title.
- Inter-based typography.

KNOWN LIMITATIONS
-----------------
- This is an alpha and has not yet been exhaustively tested across every Rockbox screen/state.
- 6G / 7G support is experimental.
- Mini-player album artwork is square; rounded dynamic artwork is deferred for a later release.
- Some Rockbox-native redraw behaviour may still be visible in the Quick Screen.
